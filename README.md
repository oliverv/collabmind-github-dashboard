# Collabmind GitHub Dashboard

A static GitHub Pages dashboard displaying all your public GitHub repositories.

## Features

- **Live repository catalog**: Shows all public repositories from your GitHub account
- **Search & filtering**: Quickly find repos by name or description
- **Category organization**: Auto-categorizes repos into APPS, AI, MCP, TOOLS
- **Fork tracking**: Distinguishes between original repos and forks
- **GitHub Actions integration**: Automatically updates the repository list daily

## Architecture

This dashboard uses a serverless architecture:

```
GitHub ──► GitHub Action ──► repos.json ──► GitHub Pages
```

- **GitHub Action** runs daily to fetch your public repositories and generate `repos.json`
- **GitHub Pages** serves the static HTML/CSS/JS from the `main` branch
- **No backend required**: Everything is static and hosted for free

## Usage

1. Clone this repository
2. Update `USERNAME` in `app.js` if needed (default: `oliverv`)
3. Push to GitHub
4. Enable GitHub Pages in repository Settings

### Enabling GitHub Pages

1. Go to **Settings** → **Pages**
2. Under **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
3. Click **Save**

Your dashboard will be available at:
```
https://oliverv.github.io/collabmind-github-dashboard/
```

### Manual Update

If you need to update `repos.json` manually:

```bash
node -e "
const fetch = require('node-fetch');
const fs = require('fs');

async function getRepos() {
  const repos = [];
  let page = 1;
  while (true) {
    const res = await fetch(\`https://api.github.com/users/oliverv/repos?per_page=100&page=\${page}&sort=updated\`);
    const batch = await res.json();
    if (!batch.length) break;
    repos.push(...batch);
    page++;
  }
  fs.writeFileSync('repos.json', JSON.stringify({ repos }, null, 2));
}
getRepos();
"
```

## Files

- `index.html` - Main page layout
- `app.js` - Frontend logic to load and display repositories
- `style.css` - Styling
- `repos.json` - Cached repository data (generated by GitHub Action)
- `.github/workflows/generate-repos.yml` - GitHub Action for automatic updates

## API Rate Limits

- GitHub REST API: 60 requests/hour per IP (anonymous)
- GitHub Action with `GITHUB_TOKEN`: 1,000 requests/hour per repository

Since we fetch repos in pages of 100, even 1000+ repositories fit within a single request.
